# WASTE-UZ — Official Web Platform
**Erasmus+ Project 101322962** — *Capacity Building in Higher Education (CBHE)*

Official domain: [https://wasteuz.uz](https://wasteuz.uz)

---

## 📌 Project Overview
**Waste Awareness Skills Training & Education — Uzbekistan (WASTE-UZ)** aims to develop and strengthen smart waste management competencies among university students in Uzbekistan through an integrated program of accredited courses, workshops, green innovation hubs, and virtual laboratory simulations.

- **Grant Agreement:** 101322962 — ERASMUS-EDU-2026-CBHE-REGION-6
- **Granting Authority:** European Education and Culture Executive Agency (EACEA)
- **Coordinator:** Al-Xorazmiy universiteti (AKHU), Urgench, Uzbekistan
- **Budget:** 302,979.07 EUR (Lump Sum)
- **Duration:** 36 Months (28.10.2026 – 28.10.2029)
- **Total Consortium Effort:** 122 Person-Months

## 🚀 Key Features
- **Project Showcase & Information Architecture:** Inspired by official Erasmus+ standards (such as greenengine.uz) with high visual polish, institutional transparency, and full project facts.
- **Interactive Virtual Laboratory (WP4):** Digital simulation portal allowing students and researchers to simulate sensor-based waste sorting, calculate CO₂ emissions avoidance, and evaluate circular economy yields.
- **Work Package Explorer:** Detailed interactive overview of all 6 Work Packages, tasks, leads, and official deliverables (D1.1–D6.3).
- **Consortium & News / Tenders Portal:** Open calls for tenders (e.g. Call for External Quality Assurance Expert, EUR 8,000), academic events, and press releases.
- **Multilingual Support:** English (official grant language) and Uzbek (national university language).
- **Admin Management Panel:** Integrated management console for announcements, tenders, and visitor inquiries.

---

## 🛠 Tech Stack
- **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Node.js, Express REST API
- **Data Persistence:** Lightweight JSON/SQLite compatible store
- **Deployment:** PM2, Nginx Reverse Proxy on Ubuntu Linux (Port 8000)

## ⚙️ Development & Deployment

### Local Development
```bash
# Install dependencies
npm install

# Run frontend dev server
npm run dev

# Run fullstack server
node server.js
```

### Production Build
```bash
npm run build
PORT=8000 npm start
```
